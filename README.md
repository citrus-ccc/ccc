# ccc

任意のディレクトリにこのリポジトリをcloneし、INSCMD.shを実行してください。

## genPコマンド

AIに伝えるプロンプトを対話式で生成するスクリプト。
プロジェクト直下にて genP を実行すると、プロジェクトを選択したり、修正依頼・コードレビューなど用途を選択します。そして、ソースコードをまとめてプロンプトにそのまま貼り付けられるテキストファイルを同じディレクトリに生成します。

## eRenコマンド

epubのファイル名が文字化けしている時にこれを使用します。正しいファイル名をepubのヘッダに埋め込まれている情報を探して引っ張り出します。メタ情報に何もなければ、どうしようもないです。

## Boopディレクトリ内スクリプト

Boopは、macOS向けの軽量でオープンソースなスクリプト実行型テキストスクラッチパッドです。JSONの整形、Base64のエンコード/デコード、テキスト変換などの日常的な処理を、オンラインツールに頼ることなくローカル環境で迅速かつ安全に実行できます。

### ✨ Boopの特徴 (Features)

*   **プライバシー優先:** すべてのテキスト処理はローカルで完結します。APIキーや顧客データ、機密情報を外部のWebサイトに送信するリスクがありません。
    
*   **ネイティブ＆軽量:** Swiftで開発されたネイティブmacOSアプリであり、非常に軽量でサクサク動作します。
    
*   **キーボードファースト:** マウスを使わずに、ショートカットキーのみで素早くテキストを処理できます。
    
*   **JavaScriptによる拡張性:** 標準で数十種類の便利なスクリプトが用意されているほか、JavaScriptを使って独自のカスタムスクリプトを簡単に追加できます。
